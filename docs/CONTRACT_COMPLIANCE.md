# 交付范围与合同符合性

以用户提供的《技术指标与交付成果》验收附件为依据，共7项指标、30条具体要求。逐条原意映射、实际案例与技术自验结论见[项目验收证据](项目验收证据.md)。功能核对在Vue问答工作台、知识资料库和“依据与过程”的实际任务数据中完成。

| 指标 | 交付能力 | 主要证据 |
|---|---|---|
| 1. 知识资源组织与构建 | 71份化工知识资料，UTF-8解析、来源、章节分段与索引 | 资料清单、三项基本检索及知识问答案例 |
| 2. 检索与知识增强 | LightRAG混合检索，主题词、细节词、实体关系、原文和引用 | 实际命中原文与后续模型输入匹配记录 |
| 3. 知识增强任务处理 | 输入、检索、知识组织、生成和连续补参 | 知识问答、缺参与同一对话补参运行记录 |
| 4. 复杂任务解析与规划 | smolagents工具调用循环、最多十步计划、方法与依赖校验 | 九步工程组合任务及逐步实际执行记录 |
| 5. 多工具选择与调用 | 九种真实业务工具，参数描述、同响应多项调用、状态、输出及前序结果引用 | 九工具注册表、第2批九次成功调用、七条input_refs和数值核对 |
| 6. 源代码交付 | 后端、Vue前端、资料、配置、锁文件、说明、示例及源码压缩包 | 包内容与源码一致性、环境排除、解压后的离线演示和API检查 |
| 7. 研究报告与验收 | Word研究报告、实际页面及功能验证证据 | 典型真实任务记录、用户工作台截图及对应研究说明 |

运行与复现步骤见根目录README。源代码包为 `dist/chem-agent.zip`，校验值为同目录 `chem-agent.zip.sha256`。报告保持既定模板，说明最终成果的目标、技术路线、算法、示例和验证结果。

技术自验结论根据实际记录生成；原始本机任务保留在被Git忽略的runs目录，随交付提供经脱敏的验收案例记录。
