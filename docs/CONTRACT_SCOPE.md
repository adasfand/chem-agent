# 项目交付范围依据

以用户提供的合同《技术指标与交付成果》验收附件图片为依据，核对七项指标及三十条具体要求。下表为范围摘要，完整条款与证据映射见[项目验收证据](项目验收证据.md)，实现说明见README与系统架构。

| 摘要条目 | 原摘要中的核心内容 | 本轮最小验收能力 |
|---|---|---|
| 1. 知识资源组织与知识库构建 | 资料整理、必要解析、分段、索引、查询与检索 | 读取支持格式，保存来源，检索原文，索引可重建 |
| 2. 知识检索与知识增强 | 按任务相关性召回知识，组织结果，将知识作为大模型上下文 | 本轮检索片段进入模型观察，答案可追溯 |
| 3. 知识增强任务处理流程 | 从任务输入到知识检索、知识组织和模型结果生成 | 同一运行中的输入、检索、答案、引用 |
| 4. 复杂任务解析与执行规划 | 分析任务、形成步骤，结合目标和工具能力组织执行 | 问题驱动的结构化有限步骤和依赖 |
| 5. 多工具选择与调用 | 工具描述、选择、参数生成、调用、状态记录及结果回用 | 多个真实工具，参数验证、记录、前序输出回用 |
| 6. 源码交付 | 核心代码、配置、依赖、运行说明、示例任务 | 源码包可在说明环境安装、启动、执行示例 |
| 7. 研究报告 | 技术路线、主要算法、验证情况、示例应用；与实物一致 | 报告的方法、文件、数值和证据与交付一致 |

附件以约定功能的演示和验证为主要依据；知识数量、工具数量、具体框架及前端布局按项目实现说明，不另设合同外的数值验收门槛。
