## 1. 项目当前状态

一套可本机安装、可用Docker启动的化工知识与计算工程：21张有来源的知识卡，LightRAG图谱/向量混合检索及明确词法回退，smolagents规划与工具调用，四种真实业务工具，带单位的前序结果引用，工作台、CLI、补参、取消、私有trace与Markdown/JSON导出。数值函数独立于模型。

按仓库保留的七项合同摘要范围，七项均有实现及可复核入口：资料组织、检索增强、完整问答流程、有限任务规划、多工具调用与回用、源码交付、研究报告。完整映射见 [CONTRACT_COMPLIANCE](CONTRACT_COMPLIANCE.md)，范围依据随包保存于 [CONTRACT_SCOPE](CONTRACT_SCOPE.md)。不把未实现的多Agent、工业物性查询或复杂流程模拟计为能力。

## 5. 复用的开源技术

未增加Python运行依赖。继续使用smolagents 1.26.0（Apache-2.0）、LightRAG 1.5.7（MIT）、FastEmbed 0.8.1（Apache-2.0）、FastAPI 0.141.1/Pydantic 2.13.5（MIT）、Pint 0.25.3（BSD-3-Clause）。容器固定uv 0.12.20和Python3.12基础镜像。选择原因、官方可复用代码和兼容性成本见 [AUDIT_AND_PLAN](AUDIT_AND_PLAN.md)，许可来源见根目录THIRD_PARTY_NOTICES和uv.lock。

## 6. 最终架构

Application/API → 单轮run_task → smolagents → Tool Registry/Execution → LightRAG或词法检索/确定性计算 → 工具观察回传 → 终态与来源 → Trace/导出。单进程、单模型任务槽、本地文件持久化。详细数据流图与错误处理见 [ARCHITECTURE](ARCHITECTURE.md)。

## 10. 剩余风险

运行方应核对物性来源、工具输入、数值和假设；以成功工具输出为计算依据。幂等历史和工作台会话在重启/过期后不恢复；原始trace含业务输入，分享前需检查。SDK适配固定于LightRAG1.5.7，升级须保留真实SDK回归。Windows、生产多人部署、全主题检索准确率与工业物性数据库尚未验证。本轮不为这些边界扩展数据库、多Agent、队列或流程编辑平台。
