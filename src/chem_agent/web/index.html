使用说明

  1. 描述问题

    支持常用单位换算、单相恒比热显热、稳态无反应混合衡算，以及配套知识查询。

  2. 补齐必要条件

    缺少比热、流量或浓度口径时，在同一任务继续回复。补充内容会生成关联的新一轮记录，旧记录仍可查看。

  3. 核对结果与依据

    数值卡片来自实际工具输出；模型说明用于解释。执行过程展示输入、单位换算、输出及失败信息；知识依据区分已引用和仅检索资料。

  4. 导出并交接

    文字报告适合阅读，JSON 记录适合追溯。未完成和等待补充的任务也能导出，但不代表已有最终计算结论。

适用范围

知识库是项目自编的教学资料，不是物性数据库。当前版本用于基础计算演示与教学核对，未实现工业流程模拟、设备设计或生产决策验证。

任务会发送到已配置的模型服务。当前浏览器会话可刷新恢复；服务重启后页面记录重置，本机 runs/ 中的执行记录保留。取消会阻止后续步骤，正在进行的模型请求可能需等待返回。
