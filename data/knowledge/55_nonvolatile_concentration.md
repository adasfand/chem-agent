# 非挥发溶质浓缩的物料衡算
来源：项目教学整理；参考美国科罗拉多大学 Boulder LearnChemE 的物料衡算与蒸发结晶教学主题：https://learncheme.com/screencasts/mass-energy-balances/；公式由溶质守恒推导。

## 浓缩关系
进料质量流量 F、溶质质量分数 w_F，浓缩液流量 P、质量分数 w_P。若只移除不含溶质的溶剂且稳态无反应，则 Fw_F = Pw_P，P = Fw_F/w_P，移除溶剂流量 V = F-P。

## 条件与防错
要求 0 < w_F ≤ w_P ≤ 1，且无溶质挥发、雾沫夹带、结晶析出或泄漏。若形成固体，应增加固相出口衡算。此式仅求物流量，不代表具备蒸发设备设计或潜热计算能力；蒸发热负荷不能直接套用恒比热显热公式。
